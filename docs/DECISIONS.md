# Engineering decisions

1. **The model chooses; code controls spending.** Eve interprets natural language and chooses catalog IDs. Code prices integer cents, fixes the recipient, saves one immutable purchase per inbound request, and checks the cap. Eve's native approval receives an exact review string checked against that saved purchase, and its human response binds to a digest of the items, amount, destination, rationale, and request. Catena remains independently authoritative. A locally asserted identity is appropriate only for one trusted operator; it is not employee authentication. Catena can require an additional approval or signature.

2. **An unresolved payment remains reserved.** SQLite stores the original request, approval, and stable payment key before submission. An atomic claim prevents duplicate local submission. Repeated calls reconcile the existing intent. An unknown create outcome needs explicit operator recovery with the same saved action and key. Only provider completion is paid; a definitive failed or blocked outcome releases the local budget reservation. Attempted payments still consume the separate operator authorization. Preserve the private ledger across restarts. Unexpected cross-chain results remain uncertain, and an unavailable provider read never silently releases funds.

3. **Reports do not invent provider accounting.** Catena exposes a monthly block but its reset and reservation semantics are unverified. The local lifetime guard remains stricter and does not reset. Reports independently use UTC calendar months, attribute settled spending to provider completion when available, and label current unresolved commitments and both budget comparisons explicitly. A scheduled handler writes one durable inbox entry per month and mode; a separate run record proves execution. Eve's built local process supplies the clock with `TZ=UTC`. It must remain running and has no missed-run catch-up. Refresh reports after reconciliation; they are local summaries, not provider usage or balance statements.

The integration follows the installed Eve 0.67.2 documentation for tools, human approval, evals, and schedules, and the public types and README of [Catena SDK 0.5.0](https://www.npmjs.com/package/@catena/sdk/v/0.5.0).
